# Sayan Sarkar — Personal Portfolio

A responsive, cinematic personal portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page content and embedded soundtrack players
- `styles.css` — visual design and responsive layout
- `script.js` — mobile navigation and current year

## Preview locally
Open `index.html` in a browser. The Google Fonts and YouTube players require an internet connection.

## Publish with GitHub Pages
1. Extract this ZIP.
2. Open your repository: `sayansarkar0223/sayansarkar.github.io`.
3. Upload/replace `index.html`, `styles.css`, `script.js`, and `README.md` in the repository root.
4. Commit the changes.
5. In repository Settings → Pages, make sure the publishing source is set to the `main` branch and `/ (root)`.
6. Allow GitHub Pages a few minutes to deploy, then refresh the live URL.

## Before treating this as a final CV/portfolio
- Confirm current job title, employer, dates and achievements before publishing professional claims.
- Add verified acting credits (titles, roles, production details) when available.
- Add your own photographs and approved official film artwork when available. The current visual elements are CSS illustrations, not personal photographs or official posters.
- Review all wording and links before publishing.

# Sayan Sarkar — Cinematic Portfolio

A responsive, cinematic personal portfolio built with plain HTML, CSS and JavaScript for GitHub Pages.

## Files
- `index.html` — page structure and content
- `styles.css` — visual design, responsive layouts and motion
- `script.js` — navigation, scroll progress, reveal effects, cinema panel and hidden terminal

## Before publishing: personalise these items
Search in `index.html` and `script.js` for the following placeholders and replace them:

1. `YOUR_EMAIL@example.com` — your real contact email (appears twice).
2. `https://www.linkedin.com/` — your actual LinkedIn profile URL.
3. `https://www.instagram.com/` — your actual Instagram URL, or remove that link if you prefer.
4. Review the About, career, acting and education descriptions. Add exact dates, role titles, verified achievements and project credits only where you are comfortable sharing them.
5. Add a resume PDF to the repository (for example `assets/Sayan-Sarkar-Resume.pdf`) and add a visible download link when the final file is ready.
6. Add your own photographs and acting stills after checking you have permission to publish them.

The current page intentionally avoids invented job dates, metrics, film credits and personal contact details. The film list reflects personal favourites discussed in conversation; change it freely.

## Preview locally
Open `index.html` in a browser. For a more realistic local preview, use VS Code's Live Server extension.

## Publish on GitHub Pages
For the current project repository `sayansarkar.github.io` under account `sayansarkar0223`:

1. Open https://github.com/sayansarkar0223/sayansarkar.github.io
2. Back up or download the current repository before replacing files.
3. Upload `index.html`, `styles.css`, `script.js` and this README to the repository root. Keep the exact lowercase filenames.
4. Commit the changes to the branch configured for Pages (usually `main`).
5. Open **Settings → Pages** and confirm **Deploy from a branch**, branch `main`, folder `/ (root)`.
6. Open the **Actions** tab and wait for the Pages build and deployment workflow to finish successfully.
7. Visit https://sayansarkar0223.github.io/sayansarkar.github.io/

The repository name is a project site under the username `sayansarkar0223`, so the current URL includes `/sayansarkar.github.io/`. To use the shorter personal-site URL `https://sayansarkar0223.github.io/`, create a separate repository named exactly `sayansarkar0223.github.io` and publish the same site there.

## Notes
- The Google Fonts are loaded from Google Fonts; the design has sensible system fallbacks if the font service is unavailable.
- No backend, build step, package manager or API key is required.
- The page respects `prefers-reduced-motion` and includes mobile navigation.
